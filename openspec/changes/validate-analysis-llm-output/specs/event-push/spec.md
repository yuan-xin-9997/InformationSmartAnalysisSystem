## MODIFIED Requirements

### Requirement: 分析任务完成后自动推送

当一条启用状态的推送规则触发方式为 `on_run` 时，系统 MUST 仅在其选定的分析任务的一次运行**状态为 `succeeded`** 后，为该规则执行一次增量推送。推送的触发判定 MUST 依据运行的最终状态，而 MUST NOT 仅依据「执行过程未抛出异常」——运行可能因全部条目分析失败而被判为 `failed` 却未抛出异常，此时 MUST NOT 触发推送。分析任务失败时 MUST NOT 触发推送。

#### Scenario: 任务成功完成后触发自动推送
- **WHEN** 规则触发方式为 `on_run` 且选定任务 A，任务 A 的一次运行成功完成并新生成了分析结果
- **THEN** 系统自动为该规则执行一次增量推送，把新生成的事件发送到规则配置的收件人

#### Scenario: 任务失败时不触发推送
- **WHEN** 规则选定任务 A 的一次运行以失败结束
- **THEN** 系统不触发该规则的推送

#### Scenario: 全部条目分析失败时不触发推送

- **WHEN** 规则选定任务 A 的一次运行未产出任何有效分析结果（全部条目分析失败），运行状态为 `failed`，但执行过程未抛出异常
- **THEN** 系统不触发该规则的推送，不向任何收件人发出邮件
