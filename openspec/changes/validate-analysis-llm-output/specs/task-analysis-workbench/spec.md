## ADDED Requirements

### Requirement: 分析输出有效性校验

系统 MUST 在把 LLM 分析输出判定为成功之前校验其有效性：输出文本 MUST 非空（去除首尾空白后仍有内容），且 MUST NOT 因达到输出长度上限而被截断。

当 LLM 响应因达到输出长度上限而截断时，系统 SHALL 以更大的输出长度预算自动重试一次；重试后仍截断的输出 MUST 判为失败。当响应正文为空但模型返回了独立的推理/思考内容字段时，系统 SHALL 回退使用该字段，二者皆空时 MUST 判为失败。

校验不通过的分析结果 MUST NOT 落库，其对应信息条目的「已分析」标记 MUST NOT 被置位，运行摘要 MUST NOT 将其计入生成结果数。系统 SHALL 在不通过时记录 WARNING 级任务日志（含具体条目标识），并在运行摘要中显式给出失败条目数，使失败不被静默吞掉。

系统 SHALL 保证分析调用的输出长度预算不低于一个安全下限，以避免推理模型在思考阶段耗尽预算而返回空结果；当生效配置低于该下限时，系统 SHALL 按安全下限执行并记录 WARNING。

一次分析运行在未产出任何有效结果且存在失败条目时，其状态 MUST 为 `failed`；部分成功时状态为 `succeeded` 且摘要中标注失败数。

#### Scenario: 输出被截断时自动以更大预算重试

- **WHEN** 一次 LLM 调用的响应因达到输出长度上限而被截断
- **THEN** 系统以翻倍的输出长度预算自动重试一次该调用，并在任务日志记录 WARNING

#### Scenario: 重试后仍被截断则判为失败

- **WHEN** 一次 LLM 调用在重试后仍然被截断
- **THEN** 系统判定该条目分析失败：不写入分析结果、不置该条目为已分析、不推进水位线，并在任务日志记录含该条目标识的 WARNING

#### Scenario: 空正文回退推理内容字段

- **WHEN** LLM 响应正文为空但返回了非空的推理/思考内容字段
- **THEN** 系统使用该推理内容字段作为分析结果，并在任务日志记录 WARNING

#### Scenario: 空输出被判为失败而非成功

- **WHEN** LLM 响应正文与推理内容字段均为空
- **THEN** 系统判定该条目分析失败，不写入分析结果、不置该条目为已分析，运行摘要中的生成结果数不增加

#### Scenario: 单条失败不中断整批分析

- **WHEN** 一个批次中某一条目的分析输出校验不通过，其余条目正常
- **THEN** 系统跳过该条目继续分析其余条目，运行状态为 `succeeded`，摘要显示已生成的结果数与失败条目数

#### Scenario: 全部条目失败时运行判为失败

- **WHEN** 一次分析运行的所有条目分析输出校验均不通过
- **THEN** 该运行状态为 `failed`，不生成任何分析结果，且其错误信息说明全部条目分析失败

#### Scenario: 配置的输出预算低于安全下限时按下限执行

- **WHEN** 生效配置中的输出长度预算低于系统安全下限
- **THEN** 系统按安全下限请求 LLM，并在任务日志记录 WARNING 提示该配置过小
